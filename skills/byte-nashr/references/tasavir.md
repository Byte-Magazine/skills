# پردازش تصاویر

سایت با `images: { unoptimized: true }` در `next.config.ts` ساخته
می‌شود (Next.js با `output: "export"`)؛ یعنی هیچ پردازش خودکار تصویر
هنگام build انجام نمی‌شود — هر فایلی که در `content/`/`public/` بگذاری
همان‌طور روی سایت سرو می‌شود. پس بهینه‌سازی قبل از commit، مسئولیت این
اسکیل است.

## SVG

فایل‌های SVG **بدون هیچ تغییری** کپی می‌شوند. سایت از قبل SVG را مستقیم
استفاده می‌کند (نمونه‌های موجود: `content/issues/00000110/xdp/img/img1.svg`،
`content/issues/00000111/write-paper/illustration.svg`) — نیازی به
بررسی پشتیبانی نیست، تأیید شده است.

## تصاویر رستری (PNG/JPG/WebP)

سیاست بر اساس حجم فایل:

| حجم فایل | اقدام |
| --- | --- |
| کمتر از ۱۵۰ کیلوبایت | بدون تغییر باقی می‌ماند |
| بین ۱۵۰ تا ۳۰۰ کیلوبایت | به‌طور پیش‌فرض بدون تغییر؛ تبدیل به WebP فقط اگر بی‌دردسر و بدون افت کیفیت محسوس ممکن باشد — اجباری نیست |
| بیشتر از ۳۰۰ کیلوبایت | **باید** به WebP تبدیل شود |

### روش تبدیل

از ابزار `cwebp` استفاده کن (روی این سیستم نصب است):

```bash
cwebp -q 80 input.png -o output.webp
```

- با کیفیت ۸۰ شروع کن.
- اگر خروجی هنوز بیشتر از ۳۰۰ کیلوبایت بود، کیفیت را پله‌پله کاهش بده
  (۷۰، سپس ۶۰، سپس ۵۰) و دوباره امتحان کن.
- **هرگز کیفیت را زیر ۴۰ نبر** بدون این‌که موضوع را به کاربر گزارش
  کنی — اگر در کیفیت ۴۰ هم هنوز حجم بالای ۳۰۰ کیلوبایت است، به کاربر
  اطلاع بده و نتیجهٔ فعلی را با توضیح ارائه بده، خودسرانه فراتر کاهش
  نده.
- بعد از تبدیل، فایل مبدأ (png/jpg اصلی) حذف می‌شود و فقط نسخهٔ `.webp`
  باقی می‌ماند؛ نام فایل همان می‌ماند، فقط پسوند عوض می‌شود
  (`cap.png` → `cap.webp`).
- هر ارجاع به آن تصویر در متن `index.mdx` (چه در Markdown image syntax
  `![...](./img/cap.png)` و چه در JSX مثل
  `<div>![](./img/cap.png)</div>`) باید به پسوند جدید به‌روزرسانی شود.

## مقصد فایل‌ها

- تصاویر داخل متن مقاله → `content/issues/<issue>/<slug>/img/`
- عکس نویسنده (جدید یا آپدیت‌شده) → `public/img/authors/` (طبق قرارداد
  موجود؛ نمونه‌ها: `public/img/authors/aidaJabbari.png`،
  `public/img/authors/alialmasi.jpg`)

## بعد از پردازش

خلاصه‌ای از تغییرات حجم را به کاربر گزارش بده: کدام فایل‌ها تبدیل شدند،
حجم قبل/بعد، و کدام‌ها بدون تغییر ماندند و چرا.
